# 模块开发接入说明

## 分工边界

公共底座统一维护 `identity`、`catalog`、`order`、`payment`、`refund`、`verification` 和 `shared`。
具体模块开发人员在独立包中开发，例如 `scenic`、`hotel`、`dining`、`meeting`。不得重复实现订单、支付、退款、库存和核销。

## 数据关联

| 业务扩展对象 | 公共关联字段 |
| --- | --- |
| 资源业务资料 | `bf_resource.id` |
| SKU 业务规则 | `bf_resource_sku.id` |
| 日期/时段库存 | `bf_inventory.id` |
| 订单业务扩展 | `bf_order.id` |
| 游客、入住人等明细 | `bf_order_item.id` |
| 电子票 | `bf_verification.order_item_id` |

新增数据库结构必须创建新的 Flyway 迁移，禁止修改已经提交和执行的 `V1`～`V7`。

## 本地启动

1. 安装 JDK 17、MySQL 8 和 Redis 7。
2. 创建数据库 `beifanghui`。
3. 将 `config/application-env.example` 中的配置复制到 IDEA 运行配置并填写本地密码。
4. 运行 `BeifanghuiBackendApplication`，Flyway 会自动迁移数据库。
5. 使用 `http/api-examples.http` 完成登录、资源、订单、支付和电子票联调。

## Git 协作

模块开发人员从集成分支创建 `feature/<module-name>`，只提交源代码、迁移、测试和文档。
禁止提交 `.idea`、`target`、本地密码、访问令牌和 `http/local-api.http`。
